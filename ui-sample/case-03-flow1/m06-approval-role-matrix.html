Approval Role Matrix

Which role may perform which approval transition, for one Application. Derived from that Application's own Machines' Permissions — this page doesn't invent a new permission model, it just re-projects ProcessEdge (already rendered per-transition on /{machineID}/process-map) role-first instead of transition-first.

  • SubmitDraft → In Review
    ✓ Admin✓ Member
  • Approve — FinanceIn Review → Finance OK
    ✓ Admin✓ Finance Reviewer
  • Approve — LegalFinance OK → Legal OK
    ✓ Admin✓ Legal Reviewer
  • Approve — DirectorLegal OK → Approved
    ✓ Admin✓ Director
  • Rejectany pending state → Rejected
    ✓ Admin✓ Finance Reviewer✓ Legal Reviewer✓ Director
  • ReopenRejected → Draft
    ✓ Admin✓ Member

Chips list the roles holding a Permission for that transition's Event. A role that holds none of a transition's grants never sees the action on that record's Detail page.
